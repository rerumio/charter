# Route every text to its code — one file, one of the two, never a blend

A clause that states a position and a figure in one breath cannot be amended: loosen the figure
and the position moves with it. Worse, the same subject then lives in two files
that drift apart, and whoever builds from the wrong one is building the wrong thing.

- **Strip it to decide.** Take out every figure and state. If something is left, it is
  a principle. If what is left is a figure or a state, it is a mechanic.
- **Split a subject across the codes rather than bending one.** "Reading is always free" is a
  principle, "admission needs a published weight of votes from a published number of distinct
  voters" is a mechanic. Two files, one subject, and each amendable on its own.
- **Refuse the mixed clause.** A sentence that names both a promise and a threshold belongs to
  neither code. Cut it in two and place each half.
- **Point across, never restate.** A text may name the file that governs the other half. It
  never paraphrases it: two copies of a rule are one rule and one lie waiting.
- **The exception.** A mechanic states an implementation constraint when a guarantee demands
  one — immutability, a permanent address, an append-only record. That is foundation, and it
  stays in mechanics.
