# Hold every file to the template — one shape for the whole folder

A folder where each file invents its own headings cannot be read as one system. The shape lives in
[../TEMPLATE.md](../TEMPLATE.md).

- **Start from the template.** A new file is a copy of it — same headings, same order, guiding
  comments deleted.
- **Keep the headings verbatim.** Nothing renamed, reordered, merged or invented.
- **Restore the shape on every edit.** Leave the file in the template's shape, never deepen a drift.
- **A file that cannot fit is a template question.** Change the template for the whole folder, never
  bend one file quietly.
- **The exception.** Only the Appendix may be omitted; the template and these rules are the only
  files the shape does not govern.
